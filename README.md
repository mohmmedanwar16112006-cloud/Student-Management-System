# Student Management System

A simple console-based Student Management System built using C++.

## Description

This project is designed to manage student records through a simple menu system.
It allows users to add, display, search, and delete student information.

## Features

- Add new students
- Display all students
- Search for a student by ID
- Delete student records
- Save data to a file

## Technologies Used

- C++
- File Handling
- Structs
- Arrays
- Loops and Conditions

## Purpose

This project was created to practice C++ programming fundamentals and improve problem-solving skills as a Computer Science student.
